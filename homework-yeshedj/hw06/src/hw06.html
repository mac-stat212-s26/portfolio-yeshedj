  • It tries to replace every NA value in df with the value “0”

How does it work if df is a numeric vector? Break the code down.

  • It would make a vector of the same length as df, then index to only select the TRUE positions which are at 11 and 21, and then will replace the NA’s by assigning “0” to those selected positions.

df <- c(1:10,NA,11:20, NA)

Why does it work if df is a tibble with quantitative variables such as mtcars?

  • It would work since a tibble can be indexed as if it’s a matrix since the same dimensions would be returned with is.na(df) and if all the columns are numeric and properly compatible, every TRUE would be replaced with 0.

df <- mtcars

#Adding missing values

Ex 1

Write a function called get_acs1() that gets 1-year ACS data for a given year for a set of user specified variables for all states. Function arguments should include: - year: Within your function check that this is between 2005 and 2022 and not 2020 (data only available from 2005-2022 except for 2020). If the year is outside this range, include stop("Helpful error message here") to display a helpful error message to the user. - variables: A character vector of variable names to obtain. e.g., c("B02015_009", "B01003_001"). Note that these don’t have “E” or “M” at the end. You’ll always return the “E” version (for the estimate). See next argument for the “M” version. Make sure your function can also handle variables like NAME. - include_moe: TRUE/FALSE indicator of whether to additionally include the “M” version (for the margin of error on the estimate). Set the default to TRUE. - key: Census API key (if you have trouble getting a key, email the instructor as soon as possible) Your function should include a Sys.sleep(0.5) at the beginning to pause code execution for 0.5 seconds. While the Census API does not seem to have a rate limit when you provide an API key, include this pause just to be safe.

Code
library(tidyverse)
library(httr)
library(jsonlite)

get_acs1 <- function(year, variables, include_moe = TRUE, key) {
  Sys.sleep(0.5)
  
  if (!year %in% c(2005:2019, 2021:2022)) {
    stop("Year must be between 2005 and 2022, excluding 2020.")
  }
  name_var<- variables[variables == "NAME"]
  coded_vars<- variables[variables != "NAME"]
  
  get_parts <- c(name_var, if (length(coded_vars) > 0) paste0(coded_vars, "E"),
                 if (include_moe && length(coded_vars) > 0) paste0(coded_vars, "M")
                 )
  get_string <- paste(get_parts, collapse = ",")
  
  url<-paste0(
    "https://api.census.gov/data/", year,
    "/acs/acs1?get=", get_string,
    "&for=state:*",
    "&key=", key
  )
  response <- GET(url)
  
  if (status_code(response) != 200) {
    stop("API request failed with status: ",status_code(response))
  }
  raw <- content(response, as="text", encoding="UTF-8")
  parsed<- fromJSON(raw)
  
  df <- as.data.frame(parsed[-1, ],stringsAsFactors=FALSE)
  colnames(df) <- parsed[1, ]
  df <- df |> mutate(year = year)
  
  return(df)
}

acs_clean <- acs_map |>

Goal

Analyze Stack Overflow badges and posts data using SQL queries.

Start at https://data.stackexchange.com/stackoverflow/query/new. For each exercise, record the query you used in the qmd file; you run the query on https://data.stackexchange.com/stackoverflow/query/new to ensure you get the desired result.

Ex 1

Count the number of total badges that have been given out. Hint: count the number of rows in the relevant table.

ANSWER: Each of the rows in the badges table represents one badge that is given out to one user so counting all of these rows will give us the total number of badges that were given out.

SELECT COUNT(*) AS TotalBadges
FROM Badges

Ex 2

Find how many times each badge has been awarded, sorted from most awarded to least awarded.

ANSWER: This groups the badges by name and counts the rows in each group and then sorts descending so that the most-awarded badge shows up first

SELECT Name, COUNT(*) AS TimesAwarded
FROM Badges
GROUP BY Name
ORDER BY TimesAwarded DESC

Ex 3

Find a badge that looks interesting to you. Find all the user DisplayNames that have received the badge, along with the date at which they received it.

ANSWER: “Lengendary’ badge is awarded for earning more than 200 reputation in a day which is a big achievement. This finds all th users who have earned this and when

SELECT u.DisplayName, b.Date AS DateAwarded
FROM Badges b
JOIN Users u ON b.UserId = u.Id
WHERE b.Name = 'Legendary'
ORDER BY b.Date

Ex 4

Show the users who have received the most badges, along with how many they have received.

ANSWER: This groups the badges by user and counts per each user and then sorts descending so that the users with the most badges appear first. Joining makes it so the DisplayName is readable alongside of the count.

SELECT u.Id AS UserId, u.DisplayName, COUNT(*) AS TotalBadges
FROM Badges b
JOIN Users u ON b.UserId = u.Id
GROUP BY u.Id, u.DisplayName
ORDER BY TotalBadges DESC

Ex 5

Export a CSV file containing information about each user: DisplayName, Id, Reputation, and CreationDate. Because any queries that return more than 50,000 results return a random subset of 50,000 results, include a sort on the user ID variable to ensure that the first 50,000 users are retrieved. Name your file users.csv.

ANSWER: The ‘Top 50000’ with ‘order by id’ makes it so that we get 50000 users who have the lowest id’s

SELECT TOP 50000
  DisplayName,
  Id,
  Reputation,
  CreationDate
FROM Users
ORDER BY Id

Ex 6

Make a table that has each user’s total number of badges, and export this file as a CSV named badges.csv. Continue to include a sort on the user ID variable so that this data has information on the same first 50,000 users. Hint: Start with the badges table, join information from users, and perform some grouped summaries.

ANSWER: This starts with badges and joins to users for the DisplayName. Then, it filters to the first 50000 users by a subquery and grouping by user as well as counting by the rows gives the total of the users badges.

SELECT b.UserId, u.DisplayName, COUNT(*) AS TotalBadges
FROM Badges b
JOIN Users u ON b.UserId = u.Id
WHERE u.Id IN (SELECT TOP 50000 Id FROM Users ORDER BY Id)
GROUP BY b.UserId, u.DisplayName
ORDER BY b.UserId

Ex 7

Make a table that has each user’s total number of posts and total number of upvotes the user has cast, and export this file as a CSV named posts.csv. Continue to include a sort on the user ID variable so that this data has information on the same first 50,000 users. Hint: Start with the posts table, join information from users, and perform some grouped summaries.

ANSWER: This starts from posts and joins to users for display info. Then, it filters to the first 50000 users and groups them by user to count the posts and total up the score column.

SELECT p.OwnerUserId AS UserId, u.DisplayName,
       COUNT(*)      AS TotalPosts,
       SUM(p.Score)  AS TotalUpvotes
FROM Posts p
JOIN Users u ON p.OwnerUserId = u.Id
WHERE u.Id IN (SELECT TOP 50000 Id FROM Users ORDER BY Id)
GROUP BY p.OwnerUserId, u.DisplayName
ORDER BY p.OwnerUserId

Ex 8

Calculate the number of comments made per user, and the total number of upvotes across all comments made per user (this is the sum of the Score variable under the Comments table) and export this as a CSV file named comments.csv. Continue to include a sort on the user ID variable so that this data has information on the same first 50,000 users.

ANSWER: This starts from comments and joins to users. Then, it filters to the 50000 users and groups by the users to count the comments and totals up the score.

SELECT c.UserId, u.DisplayName,
       COUNT(*)     AS TotalComments,
       SUM(c.Score) AS TotalCommentUpvotes
FROM Comments c
JOIN Users u ON c.UserId = u.Id
WHERE u.Id IN (SELECT TOP 50000 Id FROM Users ORDER BY Id)
GROUP BY c.UserId, u.DisplayName
ORDER BY c.UserId

Ex 9

Import these four datasets into R. Visualize the relationship between the four datasets. Include at least two visualizations.

Your goal should be to weave together a compelling story about how users on Stackoverflow earn badges through their activity on the site.

ANSWER: The plots show the posting activity as the strongest driver of accumulating the badges as users with more answers and questions will earn more badges. Another important factor for the badges is commenting which also has a strong positive relationship but has a slight more noise to the graph. This shows that commenting by itself may not be enough to earn the badges, rather the amount of posts and their frequency matter much more.

Code
library(tidyverse)

users <- read_csv("users.csv")
badges<- read_csv("badges.csv")
posts <- read_csv("posts.csv")
comments<- read_csv("comments.csv")

activity <- users |>
  left_join(badges, by = c("Id" ="UserId")) |>
  left_join(posts,by = c("Id" = "UserId")) |>
  left_join(comments,by = c("Id" ="UserId")) |>
  mutate(
    TotalBadges = replace_na(TotalBadges, 0),
    TotalPosts = replace_na(TotalPosts, 0),
    TotalUpvotes = replace_na(TotalUpvotes, 0),
    TotalComments = replace_na(TotalComments, 0),
    TotalCommentUpvotes = replace_na(TotalCommentUpvotes, 0)
  )

activity |>
  filter(TotalPosts > 0, TotalBadges >0) |>
  ggplot(aes(x = TotalPosts, y = TotalBadges)) +
  geom_point(alpha = 0.2, size = 0.8,color = "steelblue") +
  geom_smooth(method = "lm", se = FALSE, color = "darkred", linewidth=1)+
  scale_x_log10() +
  scale_y_log10() +
  labs(
    title = "Relationship of More Post Activity and Badges",
    subtitle = "Each point is one Stack Overflow user (log–log scale)",
    x = "Total posts (log scale)",
    y="Total badges earned (log scale)"
  ) +
  theme_minimal()
